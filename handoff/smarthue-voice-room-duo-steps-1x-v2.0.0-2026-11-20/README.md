# Siri off/on · iPhone Duo · native 1x step images

21 PNG frames rendered directly from the three v2.0.0 on/off Lottie assets, using the bundled CanvasKit/Skottie software renderer and original embedded images/fonts. No browser screenshot crop, no resampling and no use of one variant as a resized substitute for another.

Project device/layout mapping (canvas sizes, not physical screen resolution):
- 466×444: iPhone Duo gập dọc.
- 951×669: iPhone Duo mở ngang.
- 473×669: iPhone Duo mở ngang, partially folded.

Each folder contains 7 still frames: 0,96,144,180,266,350,395. PNG pixel dimensions match the folder's native canvas exactly. Timeline is 6.6s, 60 FPS, speed=1, loop=true, frame range [0,396).

Images document the steps; integrate the original .lottie asset rather than playing these as an image sequence. These PNGs are native-canvas raster renders, not a performance check on a physical device.
